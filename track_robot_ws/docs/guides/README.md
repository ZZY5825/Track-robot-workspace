# Operator Guides

This directory contains current, task-oriented procedures for operating and
validating the Track Robot workspace.

- `human-tracking/` covers human-tracking replay and validation.
- `semantic-search/` covers semantic-search live checks, recording, replay,
  and evaluation.

Keep executable user procedures here. Architecture belongs under
`docs/architecture/`; dated implementation history belongs under
`docs/development/plans/`; package-only API and hardware integration details
remain beside the owning package under `src/`.
