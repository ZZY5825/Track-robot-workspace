# Semantic Search Phase 1 Checkpoint

**Date:** 2026-07-15

**Branch:** `feature/semantic-search-phase1`

**Phase 0 base:** `8927e5ca2ac015ec3ac199901df3a637546fe4cc`

**Scope:** This checkpoint closes the passive Phase 1 engineering baseline. It
does not claim released semantic-search accuracy, 3D fusion, temporal memory,
trained DINO-to-text alignment, or any motion behaviour.

## Delivered runtime

- DINOv3 preprocessing now preserves aspect ratio and records inverse geometry.
  It is benchmarked separately and is never compared directly with CLIP text
  vectors.
- The opt-in ROS 2 Foxy worker accepts versioned text queries, caches text
  embeddings, owns exactly one aligned image-text visual tower per frame, and
  publishes only `SemanticRegionArray` plus compact diagnostics.
- The selected deployment configuration is isolated official OpenAI CLIP
  `ViT-B/32`, with a 2x2 crop grid. The 4x4 grid was measured but rejected for
  the default because its complete-path P95 exceeded the 150 ms target.
- Timestamp rollback drops the rollback frame and resets the source-time
  scheduler. Padding-dominated crops are excluded before region scoring.
- The replay probe deterministically samples 32 image messages and 32 LiDAR
  messages from the closed legacy DB3, records every sampled-message hash, and
  writes compact observations plus full provenance.
